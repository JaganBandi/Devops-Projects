# Linux Server Health Monitoring Script

## Project Overview
This project monitors Linux server health using Bash shell scripting.

## Technologies Used
- Linux
- Bash
- Git
- GitHub

## Features
- Checks hostname
- Checks disk usage
- Checks memory usage
- Checks CPU load
- Shows logged-in users
- Counts running processes

## How to Run

chmod +x healthcheck.sh

./healthcheck.sh
